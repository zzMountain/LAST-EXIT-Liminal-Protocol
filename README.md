# LAST EXIT: Liminal Protocol

Unity-головоломка о посадке пассажиров в автобусы и поиске ECHO. Кампания из 15 уровней, управление мышью и касанием, портретная и альбомная ориентации.

## Запуск

1. Клонируйте репозиторий: `git clone https://github.com/zzMountain/LAST-EXIT-Liminal-Protocol.git`.
2. Установите **Unity 2022.3.62f2** через Unity Hub. Для экспорта в браузер добавьте модуль **WebGL Build Support**.
3. В Unity Hub выберите **Add project from disk** и корень клона — папку с `Assets`, `Packages` и `ProjectSettings`.
4. Дождитесь импорта ассетов и восстановления пакетов. При первом открытии нужен интернет для Unity Package Manager.
5. Откройте `Assets/_LAST_EXIT/Scenes/StationL07.unity` и нажмите **Play**. В Editor кампания начинается с первого уровня.

Перетаскивайте автобусы по горизонтали, совмещая дверь с очередью нужного маршрута. Доступные пассажиры садятся автоматически. На уровнях с ECHO используйте CCTV, выбор пассажира на поле и карантин. Обучение и подсказки встроены в игру.

## Код и контент

| Путь | Содержание |
| --- | --- |
| `Assets/_LAST_EXIT/Runtime/Domain` | Состояние поля и правила посадки |
| `Assets/_LAST_EXIT/Runtime/Content` | Загрузка и проверка данных уровней |
| `Assets/_LAST_EXIT/Runtime/Presentation` | Ввод, UI, анимация и звук |
| `Assets/_LAST_EXIT/Runtime/Platform` | Прогресс и интеграция Яндекс Игр |
| `Assets/_LAST_EXIT/Scenes/StationL07.unity` | Основная игровая сцена |
| `Assets/_LAST_EXIT/Art`, `Audio`, `ArtLab` | Модели, материалы, шрифт, звук и художественные инструменты |
| `Assets/_LAST_EXIT/Tests` | EditMode и PlayMode тесты |
| `Assets/Plugins/WebGL`, `Assets/WebGLTemplates/LastExit` | Браузерные плагины и шаблон |
| `SourceData/Levels` | Исходные JSON уровней, вариантов и схема |

Редактируйте уровни в `SourceData/Levels`, затем выполните **LAST EXIT → Gameplay → Sync LEVEL-01 to LEVEL-15** вне Play Mode. Импортированные копии уже включены в репозиторий. Раскладки уровней имеют статус прототипа.

Для обычного запуска не нужны внешние папки, Python, Blender или инструменты ИИ. Необязательные команды авторинга звука и снятия художественных превью рассчитаны на исходную рабочую среду разработчика; готовые игровые ассеты включены. Команды повторной сборки сцены/применения оформления меняют её настройки и не нужны для запуска.

## Тесты

Откройте **Window → General → Test Runner**, выполните **Run All** отдельно для EditMode и PlayMode. Также доступны **LAST EXIT → Gameplay → Run EditMode Tests / Run PlayMode Tests**. Перед запуском сохраните изменения сцен и выйдите из Play Mode. Результаты пользовательского runner находятся в локальной `TestResults`, которая не входит в Git.

## WebGL

Выйдите из Play Mode, сохраните сцену и выберите **LAST EXIT → Gameplay → Build Yandex Release WebGL**. Экспорт появится в `Builds/WebGL_Yandex_FullFinal_20261108`. Для локального просмотра запустите HTTP-сервер из папки экспорта, например `python -m http.server 8000`, и откройте `http://localhost:8000`. Через `file://` сборка не запускается.

Для автоматической сборки на Windows с установленной Unity CLI: закройте Editor этого проекта и выполните `./Tools/Build-WebGL.ps1` в PowerShell.

SDK Яндекс Игр, облачные сохранения и реклама требуют проверки в окружении платформы; локальный запуск использует предусмотренный fallback. Проверка на физическом телефоне и приёмка платформой отдельно от ревью исходников.
